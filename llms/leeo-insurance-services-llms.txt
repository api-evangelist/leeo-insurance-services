# LEEO Insurance Services

> LEEO (formerly Fairmatic, rebranded December 2025) is a San Francisco-based managing general agent
> for commercial auto insurance. It underwrites and prices fleet policies using telematics collected
> from drivers' phones through the LEEO mobile SDK, and rewards safer driving with renewal credits
> and cashback. LEEO exposes a read-only REST Fleet Telematics API that returns the fleet's driver
> roster, trip histories, trip paths and driving events, and daily/weekly driver safety scorecards.
> LEEO is backed by Battery Ventures, Foundation Capital, and Aquiline Technology Growth.

## APIs

- [LEEO Fleet Telematics API](https://docs.leeoinsurance.com/leeo-apis/): Read-only REST API over
  fleet drivers, trips, driving events, and aggregate driver safety scores. Base URL
  `https://api.leeoinsurance.com/api/v1`. Authenticated with a fleet-scoped API key sent as
  `Authorization: APIKEY <fm_api_key>`. Rate limited to 5000 requests per minute per fleet.

### Operations

- `GET /drivers` — list all drivers in the fleet (paginated, max 100 per page)
- `GET /driver/{driver_id}/trips` — list a driver's trips from a start date (paginated, max 100)
- `GET /trip/trip_id/{trip_id}` — trip detail with trail path and events (5 per page)
- `GET /trip/tracking_id/{tracking_id}` — trip detail by SDK-supplied tracking id (5 per page)
- `GET /driver-aggregate/daily` — daily driver scorecards for 1–20 drivers
- `GET /driver-aggregate/weekly` — weekly driver scorecards with daily breakdown for 1–20 drivers
- `GET /report` — presigned URL to a generated fleet report

## Key concepts

- **Insurance risk periods** — LEEO tracks the three periods defined by the California Public
  Utilities Commission. Period 1: driver logged in and available, not matched. Period 2: match
  accepted, vehicle not yet occupied. Period 3: pick-up complete, vehicle occupied. The API returns
  these as `insurance_period` values 1, 2, 3, or null for fleets that do not require them.
- **Driving events** — `event_type` 1 RAPID_ACCELERATION, 2 HARD_BRAKE, 7 PHONE_USE,
  9 OVERSPEEDING. Only OVERSPEEDING carries extra `event_data`
  (`user_speed_mph`, `speed_limit_mph`, `max_user_speed_mph`).
- **fm_score / fm_grade** — the LEEO driver safety score and its grade band, returned on daily and
  weekly aggregates.
- **Data latency** — trips become queryable roughly 4 hours after they complete. `start_date`
  parameters must fall within the last 6 months.
- **Time** — all dates and epoch timestamps are UTC; trip and event times are epoch milliseconds.
